# Частичное погашение (со стороны заемщика)

1. Заемщик нажимает<br>
   👉 **«Погасить займ частично»**

<div align="left"><figure><img src="/assets/img/7162b2511389.png" alt="" width="167"><figcaption></figcaption></figure></div>

2. Вводит сумму оплаты
3. Нажимает<br>
   👉 **«Оплатить»**
4. После оплаты<br>
   👉 в системе формируется запрос

!!! warning "Важно"

    👉 Частичное погашение не подтверждается автоматически

    👉 Его должен **подтвердить заимодатель**


<div><figure><img src="/assets/img/d7c97af45fb2.png" alt=""><figcaption></figcaption></figure> <figure><img src="/assets/img/27bf7ec5868b.png" alt=""><figcaption></figcaption></figure> <figure><img src="/assets/img/e402765d0cdc.png" alt=""><figcaption></figcaption></figure> <figure><img src="/assets/img/a2cb86e24ba1.png" alt=""><figcaption></figcaption></figure></div>

### Что делает заимодатель

1. Видит запрос в приложении
2. Проверяет поступление денег
3. Если деньги поступили:<br>
   👉 **подтверждает оплату**

<div><figure><img src="/assets/img/6dc2eca578e6.png" alt=""><figcaption></figcaption></figure> <figure><img src="/assets/img/f2353b3a149f.png" alt=""><figcaption></figcaption></figure> <figure><img src="/assets/img/1b50cb3b6078.png" alt=""><figcaption></figcaption></figure> <figure><img src="/assets/img/1d1530a88ccb.png" alt=""><figcaption></figcaption></figure></div>

### Результат

После подтверждения:

✅ Сумма займа обновляется<br>
✅ Остаток долга уменьшается автоматически
