# Частичное погашение (со стороны заёмщика)

1. Откройте сделку и нажмите **«Погасить займ частично»**.
2. Введите сумму — приложение покажет, какой остаток займа будет после оплаты.
3. Нажмите **«Оплатить»**.

!!! warning "Платёж подтверждает займодатель"
    Частичное погашение не засчитывается автоматически. Займодатель видит запрос, проверяет поступление денег и подтверждает оплату.

## Результат

После подтверждения остаток долга уменьшается, сумма в сделке обновляется.
