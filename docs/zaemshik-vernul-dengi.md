# Заёмщик вернул деньги не через приложение

Если заёмщик вернул долг наличными или переводом мимо приложения, займодатель может сам закрыть займ.

1. Откройте сделку в разделе **«Мне должны»**.
2. Нажмите **«Заёмщик вернул деньги»** («Если вернули не через приложение»).
3. Подтвердите: **«Да, закрыть займ»** — вы получили всю оставшуюся сумму.
4. Подтвердите ещё раз: **«Да, закрыть»**.

!!! danger "Действие необратимо"
    Займ закроется полностью, отменить это нельзя. Отмечайте возврат, только если действительно получили всю сумму.
