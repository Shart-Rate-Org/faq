# Келісімді ұзарту (қарыз алушы тарапынан)

* Өз келісіміңізді ашыңыз
* Батырманы басыңыз<br>
  👉 **«Мәмілені ұзарту»**

* Жаңа мерзімді таңдаңыз<br>
  👉 **Қарыздың жаңа мерзімін күнін көрсетіңіз**
* Батырманы басыңыз<br>
  👉 **«Келісім күнін жаңарту»**

### Кейін не болады

👉 Ұзарту сұранысы **қарыз берушіге жіберіледі**

👉 Сізге экранда көрсетіледі:<br>
**«Ұзарту сұранысы жіберілді. Қарыз берушінің растауын күтіңіз»**

<div><figure><img src="/assets/img/a1697b6c81c9.png" alt="" width="333"><figcaption></figcaption></figure> <figure><img src="/assets/img/76bd78629437.png" alt="" width="333"><figcaption></figcaption></figure></div>

### Қарыз беруші не істейді

1. Сұранысты қарайды
2. Ұзартуды қабылдайды немесе қабылдамайды

### Егер мақұлданса

👉 Сізге жаңа келісімді қол қою ұсынылады<br>
👉 Батырма: **«Келісімге қол қою»**\ <br>

!!! warning "Маңызды"

    * Ұзарту тек екі тарап растағаннан кейін күшіне енеді
    * Жаңа келісімге қол қойылмайынша, ескі мерзім күшінде қалады
