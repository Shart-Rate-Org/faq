# Бұл қалай жұмыс істейді

Қорғалған мәмілеге дейін төрт қадам:

1. **Кіріп, верификациядан өтіңіз.** Кіру — телефон нөмірі бойынша, верификация — ЖСН және биометрия бойынша. [Қалай кіру керек](shart-rate-osymshasyna-alai-kiruge-tirkeluge-bolady.md) · [Верификация](shart-rate-ta-verifikaciya-alai-tedi.md)
2. **Мәміле түрін таңдаңыз.** Ақшалай қарыз, бар қарызды тіркеу немесе тауарлық қарыз. Бизнеске арналған жалға беру мен бөліп төлеу — «Shart Business» бөлімінде.
3. **Талаптарды толтырып, сұраныс жіберіңіз.** Сома, мерзім, беру және қайтару тәсілі — бір минуттан аз. Екінші тарап өтінімді қосымшада қабылдайды.
4. **Шартқа қол қойыңыз.** Комиссия қосымшада төленеді, екі тарап шартқа биометриямен ЭЦҚ арқылы қол қояды. Шарт заңды күші бар және мәміледе әрқашан қолжетімді.
