# Shart Rate-ке қош келдіңіз

Shart Rate — онлайн режимде 1 минутта заңды келісімшарт жасауға арналған Қазақстандағы алғашқы қосымша.

Дос қарызы, пәтер жалдау, қызмет төлемі, серіктестік келісім — кез келген міндеттемені нотариуссыз, кезексіз және қағазсыз ресми түрде бекітуге болады.

Shart Rate арқылы жасалған келісімшарт толық заңды күшке ие және Қазақстан Республикасының соттарында қабылданады.

**Біз адамдардың уәдесін орындауын қамтамасыз етеміз.**
