# Бар қарызды тіркеу

Қарыз Shart Rate-тан тыс пайда болса (ауызша, аударыммен т.б. қарызға берсеңіз), оны ресми шартпен рәсімдеуге болады. Әрі қарай қарыз сервистің әдеттегі ережелері бойынша жүреді: өтеу, ұзарту, еске салғыштар.

## 1. Тіркеуді бастаңыз

Басты экранда **«Қарызды рәсімдеу»** → **«Бар қарызды тіркеу»** түймесін басып, осы қарызда кім екеніңізді таңдаңыз.

## 2. Талаптарды көрсетіңіз

- **Қарыз сомасы**;
- **рөліңіз** — «Қарызға бердім» немесе «Қарызға алдым»;
- **қарыздың пайда болу себебі**;
- **қарыз қашан пайда болды**;
- **қайтару мерзімі**;
- **екінші тараптың телефоны** — ол Shart Rate-та тіркеліп, верификациядан өткен болуы керек.

**«Жалғастыру»** түймесін басып, шарттың стандартты талаптарын тексеріп, **«Мәміле жасау»** түймесін басыңыз.

!!! info "4 325 000 ₸-ден асатын қарыз"
    Ірі қарыздар үшін заңгердің тегін кеңесі қажет. Себепті таңдап, **«Кеңес алу»** түймесін басыңыз — заңгер сізбен WhatsApp арқылы байланысып, талаптарды дайындайды. Жауап — 24 сағат ішінде.

## 3. Екінші тарапты шақырып, қол қойыңыз

Өтінім жасалғаннан кейін екінші тарапты шақырыңыз. Екі тарап қарызды тіркеу шартына электрондық қолтаңбамен қол қояды — [әдеттегі шарт](ec-piya-s-zin-ornatu-zgertu-zh-ne-zhat-a-ol-oyu-toly-procesi.md) сияқты.

!!! warning
    Тіркелген қарыздың мерзімі мен сомасын қосымша келісіммен өзгертуге болмайды. Қол қойғанға дейін өтінімді болдырмау керек пе? **«Өтінімді болдырмау»** түймесін басыңыз немесе қолдау қызметіне жазыңыз.
