# Қарызды толық өтеу (қарыз алушы тарапынан)

1. Мәмілені ашып, **«Қарызды толық төлеу»** түймесін басыңыз.
2. Экранда төленетін сома көрсетіледі. Қаласаңыз **алғыс айтуды** таңдаңыз (үстіне 1%, 5% немесе 10%) — алғыс сенім рейтингіңізді арттырады.
3. **«Төлеу»** түймесін басыңыз.

!!! warning "Өтеуді несие беруші растайды"
    Толық өтеу автоматты түрде аяқталмайды: несие беруші ақшаның түскенін тексеріп, қосымшада төлемді растайды.

## Нәтиже

Несие беруші растағаннан кейін:

- қарыз **«Төленді»** мәртебесін алады;
- қарыз қалдығы = 0, мәміле жабылады.

Ақшаны қосымша арқылы емес қайтарсаңыз — несие беруші [ақша қайтарылғанын өзі белгілей алады](zaemshik-vernul-dengi.md).
