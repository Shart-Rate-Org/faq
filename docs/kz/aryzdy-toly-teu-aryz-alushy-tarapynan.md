# Қарызды толық өтеу (қарыз алушы тарапынан)

1. Өз келісіміңізді ашыңыз
2. Батырманы басыңыз

**«Қарызды толық өтеу»**

<figure><img src="/assets/img/77821f964a1d.png" alt="" width="188"><figcaption></figcaption></figure>

3. Экранда төлем сомасы көрсетіледі

👉 Негізгі қарыз<br>
\+ қалауыңыз бойынша «Рақмет айту» таңдауға болады (міндетті емес)

3. Батырманы басыңыз<br>
   **«Төлеу»**
4. Төлем жасалғаннан кейін<br>
   растау сұранысы жіберіледі

!!! warning "Маңызды"

    * Қарызды толық өтеу автоматты түрде аяқталмайды
    * Оны **қарыз беруші растауы керек**

### Қарыз беруші не істейді

1. Ақшаның түскенін тексереді
2. Қосымшада төлемді растайды

### Нәтиже

Расталғаннан кейін:

✅ Қарыз статусы **«Төленді»** болады<br>
✅ Келісім толық жабылады<br>
✅ Қалған қарыз = 0
