# Ішінара өтеу (қарыз алушы жағынан)

1. Қарыз алушы<br>
   👉 **«Қарызды ішінара өтеу»** батырмасын басады

<figure><img src="/assets/img/8099afb29c99.png" alt="" width="167"><figcaption></figcaption></figure>

2. Төлем сомасын енгізеді
3. **«Төлеу»** басады
4. Төлем жасалғаннан кейін<br>
   жүйеде сұраныс қалыптасады

!!! warning "### Маңызды"

    👉 Ішінара өтеу бірден бекітілмейді

    👉 Оны **қарыз беруші растауы керек**

### Қарыз беруші не істеуі керек

1. Қосымшада сұранысты көреді
2. Ішінара төлемді тексереді
3. Егер ақша түскен болса:<br>
   👉 **растауы керек**

<figure><img src="/assets/img/41b7882c253b.png" alt="" width="188"><figcaption></figcaption></figure>

### Нәтиже

Расталғаннан кейін:

✅ Қарыз сомасы жаңартылады<br>
✅ Қалған берешек автоматты түрде азаяды
