# Ішінара өтеу (қарыз алушы жағынан)

1. Мәмілені ашып, **«Қарызды ішінара төлеу»** түймесін басыңыз.
2. Соманы енгізіңіз — қосымша төлемнен кейін қанша қалдық қалатынын көрсетеді.
3. **«Төлеу»** түймесін басыңыз.

!!! warning "Төлемді несие беруші растайды"
    Ішінара өтеу автоматты түрде есептелмейді. Несие беруші сұранысты көріп, ақшаның түскенін тексеріп, төлемді растайды.

## Нәтиже

Расталғаннан кейін қарыз қалдығы азаяды, мәмілідегі сома жаңарады.
