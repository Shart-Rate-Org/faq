# Shart Rate қосымшасына қалай кіруге / тіркелуге болады

Бөлек тіркелу жоқ: алғаш кірген кезде аккаунт өзі жасалады. Құпия сөз қажет емес — тек телефон нөмірі мен код.

## 1. «Кіріңіз немесе тіркеліңіз» түймесін басыңыз

Басты экранның төменгі жағындағы кіру түймесін басыңыз.

## 2. Телефон нөмірін енгізіңіз

!!! warning "Маңызды"
    **ЖСН-іңізге рәсімделген негізгі нөмірді** көрсетіңіз. Кодтар осы нөмірге келеді және верификация осы нөмір арқылы өтеді.

- Нөмірді енгізіңіз.
- Дербес деректерді жинауға және өңдеуге келісім белгісін қойыңыз.
- Кодты қайда жіберу керегін таңдаңыз: **WhatsApp** немесе **Telegram**.

Код таңдалған мессенджерге келеді. Келмесе — таймерді күтіп, қайта сұраңыз.

## 4. PIN-код ойлап табыңыз

PIN-код аккаунтты қорғайды және қолданба әр іске қосылған сайын сұралады.

## Дайын

Сіз қосымшадасыз. Келесі қадам — [верификациядан өту](shart-rate-ta-verifikaciya-alai-tedi.md): онсыз мәміле рәсімдеуге болмайды.
