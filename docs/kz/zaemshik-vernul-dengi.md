# Қарыз алушы ақшаны қосымша арқылы емес қайтарды

Қарыз алушы қарызды қолма-қол немесе қосымшадан тыс аударыммен қайтарса, несие беруші қарызды өзі жаба алады.

1. Мәмілені **«Маған қарыз»** бөлімінен ашыңыз.
2. **«Қарыз алушы ақшаны қайтарды»** түймесін басыңыз («Егер қосымша арқылы қайтармаса»).
3. Растаңыз: **«Иә, қарызды жабу»** — сіз қалған соманың бәрін алдыңыз.
4. Тағы бір рет растаңыз: **«Иә, жабу»**.
